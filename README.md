In my time studying a bachelor's degree in 'Electronic and Automatic Industrial Engineering' at the University of Alcalá, my introduction to coding 
was principally though the language C and MATLAB as we were showm that these would be the primary coding languages we would need for working in the
Electronics and Robotics sectors. 
However as I became more interested specifically in the Robotics sector, I came to understand that Python was also an important coding language in 
certain aspects of the field, such as artificial vision algorithms and machine learning. 
Therefore in order to challenge myself, and become more versatile in the fields of Electronics and Robotics, I decided to learn how to code in Python, 
using the free online python course at freeCodeCamp. This course, alongside thorough and detailed explanations on how each aspect of the language works,
includes countless interactive interactive programming workshops to put to test my learning. Included are also several certification projects, 
spread out between modules, that allow me to display the skills and knowledge I have gained whilst parttaking in this course.

This repository was created to store all of these certification projects and workshops.
